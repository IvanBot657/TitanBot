⚡ TitanBot v1.0.0

📥 Instalación

Paso 1 — Clonar el repositorio

Este comando descarga el código de TitanBot desde GitHub:

git clone https://github.com/IvanBot657/TitanBot.git

Paso 2 — Entrar a la carpeta

Este comando entra en la carpeta donde se descargó TitanBot:

cd TitanBot

Paso 3 — Instalar las dependencias

Este comando instala todos los paquetes que TitanBot necesita para funcionar:

npm install

Paso 4 — Iniciar TitanBot

Este comando inicia el bot:

npm start

Paso 5 — Conectar WhatsApp

Cuando TitanBot se inicie, sigue las instrucciones que aparezcan en la terminal para conectar tu cuenta de WhatsApp.

⚠️ Importante

No compartas ni publiques tokens, contraseñas, claves API o sesiones de WhatsApp.
