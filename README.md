⚡ TITANBOT

TitanBot es un bot multifunción desarrollado para administrar, entretener y añadir diferentes sistemas interactivos a grupos de WhatsApp. Está diseñado para ofrecer herramientas de administración, juegos, entretenimiento, anime, música, cartas coleccionables y sistemas especiales.

🤖 Características principales

🛡️ Administración de grupos

TitanBot incorpora herramientas para facilitar la administración de grupos de WhatsApp, permitiendo realizar diferentes acciones de gestión y configuración de manera rápida mediante comandos.

🎮 Diversión

Incluye diferentes comandos para interactuar con los miembros del grupo:

- ⚡ Retos
- ❓ Verdad
- 😂 Chistes
- 🎁 Premios
- 🍀 Suerte
- 🧩 Acertijos
- 🎭 Imitaciones
- 💕 Compatibilidad
- 💘 Crush
- 🔮 8 Ball
- 🚢 Ship

🎡 Ruleta

Sistema de ruleta para seleccionar participantes aleatoriamente dentro del grupo, con un máximo de 4 participantes, evitando seleccionar a todo el grupo.

🃏 Sistema de cartas

TitanBot cuenta con un sistema de 50 cartas coleccionables.

Cada carta puede incluir:

- Número
- Nombre
- Rareza
- Personaje
- Estadísticas
- Habilidad
- Diseño futurista

Los usuarios pueden conseguir cartas y consultar su colección.

🎌 Sistema Anime

El bot incorpora funciones relacionadas con anime y personajes, incluyendo un sistema de personajes reclamables y colección de personajes.

🏆 Ejército Dorado

Uno de los sistemas principales de TitanBot es el Ejército Dorado, un sistema de estrategia y progreso.

Los jugadores pueden:

- 🪖 Reclutar unidades
- ⚔️ Atacar a otros jugadores
- 🛡️ Defenderse temporalmente
- 🏰 Mejorar su fortaleza
- 🏋️ Entrenar su ejército
- ✨ Obtener experiencia
- 🪙 Administrar oro
- 📈 Aumentar su poder
- 🏆 Conseguir victorias

El sistema guarda el progreso de los jugadores para mantener su evolución.

🔍 Sistema de misterio

TitanBot también incorpora un sistema de investigación y misterio para grupos, pensado para crear casos interactivos entre los participantes.

🎨 Stickers

Incluye herramientas para convertir contenido multimedia en stickers y realizar diferentes acciones relacionadas con ellos.

🎵 Música y herramientas

El bot también dispone de herramientas adicionales para entretenimiento y utilización dentro de los grupos.

💾 Sistema de datos

TitanBot utiliza diferentes sistemas de almacenamiento para conservar información del bot, incluyendo archivos JSON y PostgreSQL para determinadas funciones.

Esto permite guardar información como:

- Usuarios
- Progreso
- Cartas
- Personajes
- Ejércitos
- Eventos
- Estadísticas

🌐 Tecnología

TitanBot está desarrollado principalmente con:

- Node.js
- JavaScript
- Baileys
- Express
- PostgreSQL
- Sharp
- Axios
- QR Code

Puede ejecutarse mediante servicios de alojamiento como Render y conectarse a WhatsApp mediante Baileys.

🔄 Actualizaciones

TitanBot recibirá una actualización cada 2 meses, incorporando nuevos comandos, funciones, mejoras y contenido para mantener el bot activo y ofrecer nuevas experiencias a los usuarios.

🎯 Objetivo

El objetivo de TitanBot es reunir diferentes sistemas en un solo bot para crear una experiencia completa dentro de los grupos de WhatsApp, combinando administración, entretenimiento, juegos, colecciones, progresión y sistemas interactivos.

🌟 SISTEMAS ESPECIALES

🎌 ANIME — 2 SISTEMAS DIFERENTES

TitanBot cuenta con dos sistemas de Anime con dinámicas diferentes:

🎌 Sistema Anime 1

- 🖼️ Envía una imagen del personaje.
- 👤 Permite interactuar con personajes.
- 🎯 Incluye funciones de personajes y colección.

🎌 Sistema Anime 2

- 🖼️ También utiliza imágenes.
- 🎲 Cuenta con una dinámica diferente y un poco peculiar.
- 🎌 Está pensado para hacer más entretenida la interacción con personajes de anime.

🃏 CARTAS — 2 SISTEMAS DIFERENTES

TitanBot cuenta con dos sistemas de Cartas.

🃏 Sistema de Cartas 1

- 🔢 Cartas numeradas.
- ⭐ Diferentes rarezas.
- 👤 Nombre y características.
- ⚔️ Estadísticas y habilidades.
- 📦 Sistema de colección.
- 🖼️ Las imágenes de las cartas todavía están en desarrollo y actualmente no se muestran.

🃏 Sistema de Cartas 2

- 🎲 Cuenta con una dinámica diferente para obtener y coleccionar cartas.
- 🏆 Está pensado para ampliar el sistema de colección.

🚧 Las imágenes de las cartas serán incorporadas progresivamente en futuras actualizaciones.
