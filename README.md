📥 Instalación

Paso 1 — Clonar el repositorio

git clone https://github.com/IvanBot657/TitanBot.git

Paso 2 — Entrar a la carpeta

cd TitanBot

Paso 3 — Instalar las dependencias

npm install

Paso 4 — Iniciar TitanBot

npm start
