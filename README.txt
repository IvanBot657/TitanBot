TITANBOT 4.6.0 — v2.8

ACTUALIZACIÓN PRINCIPAL
- Vinculación mediante número de teléfono con Pairing Code.
- Configura PAIRING_NUMBER en Render en formato internacional, sin + ni espacios.
- El código aparece en los logs de Render y también en la página principal del bot.
- QR web desactivado.
- Se mantienen los comandos, menú decorado, sistema XP, juegos, economía, perfiles y comando .s anime de la versión anterior.
- Node >=18.

IMPORTANTE
1. En Render crea/edita la variable PAIRING_NUMBER.
2. Usa el número completo con código de país, por ejemplo 573001234567, sin +.
3. Inicia el servicio.
4. Abre WhatsApp > Dispositivos vinculados > Vincular dispositivo > Vincular con número de teléfono.
5. Introduce el Pairing Code mostrado por TITANBOT.
